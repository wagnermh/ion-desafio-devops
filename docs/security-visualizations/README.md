# 📊 Security Visualizations Documentation

## Overview
This repository contains automated security visualizations generated by our DevSecOps pipeline.

## 📁 Structure
security-visualizations/
├── mermaid/ # Mermaid diagrams (rendered automatically in GitHub)
│ ├── pipeline.md # Pipeline flow diagram
│ ├── vulnerabilities.md # Vulnerability distribution
│ └── dependencies.md # Dependency graph
├── excalidraw/ # Excalidraw interactive dashboards
│ └── excalidraw-dashboard.json
└── security-report.md # Complete combined report

text

## 🚀 Quick Start

### View Mermaid Diagrams
1. Navigate to the `mermaid/` directory
2. Open any `.md` file in GitHub
3. GitHub renders Mermaid diagrams automatically

### View Excalidraw Dashboard
1. Go to [Excalidraw](https://excalidraw.com)
2. Click Menu (☰) → "Load from file"
3. Upload `excalidraw-dashboard.json`

### View Complete Report
1. Open `security-report.md`
2. GitHub renders all diagrams inline

## 🔄 Automation

Diagrams are generated automatically on:
- Every successful build
- Manual trigger via `workflow_dispatch`

## 📋 Diagram Types

### Pipeline Diagram
Shows the complete CI/CD pipeline flow with security gates.

### Vulnerability Distribution
Pie chart showing vulnerability severity distribution.

### Dependency Graph
Visualizes the dependency tree of your container image.

### Security Dashboard (Excalidraw)
Interactive dashboard with:
- Vulnerability summary
- Top affected packages
- Security status decision

## 🛠️ Manual Generation

To regenerate diagrams locally:

```bash
# Install dependencies
pip install -r requirements.txt

# Generate all visualizations
make generate-report

# Or individually
make generate-diagrams     # Mermaid only
make generate-dashboard    # Excalidraw only
